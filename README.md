# SC-300 Identity Labs

This repository contains hands-on identity and access management (IAM) labs aligned with the **Microsoft SC-300: Identity and Access Administrator** certification.

Each lab simulates real-world enterprise scenarios using Microsoft Entra ID and follows **Zero Trust security principles**.

- [Lab 03 – Entra User & Dynamic Group](Lab-03-Entra-User-Dynamic-Group/README.md)
- [Lab 04 – External Identity Cross-Tenant Access](Lab-04-External-Identity-Cross-Tenant-Access/README.md)
- [Lab 05 – Authentication, MFA, SSPR & Password Protection](Lab-05-Authentication-MFA-SSPR-Password-Protection/README.md)

## 🛠️ Technologies Used

- Microsoft Entra ID (Azure AD)
- Authentication Methods Policies
- Multi-Factor Authentication (MFA)
- Self-Service Password Reset (SSPR)
- Microsoft Entra Password Protection
- Administrative Units (AUs)
- Role-Based Access Control (RBAC)
- Identity Governance concepts

---

## 💼 What This Repository Demonstrates

- Identity lifecycle management
- Delegated administration using Administrative Units
- Dynamic group membership and automation
- External identity and cross-tenant access configuration
- Modern authentication and password security controls
- Foundations for Conditional Access and Zero Trust architecture

---

## 🚀 About This Project

These labs are built using a combination of guided simulations and live tenant implementations to demonstrate **real-world IAM configurations**.

The goal of this repository is to showcase practical skills in Microsoft Entra ID that align with enterprise identity security and access management roles.
